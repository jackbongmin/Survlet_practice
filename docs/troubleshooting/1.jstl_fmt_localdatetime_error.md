# [트러블슈팅] JSTL fmt:formatDate 사용 시 LocalDateTime 형변환 에러 (500 Error)

## 1. 진행 파트
- **기능**: 타임라인 피드형 게시판 구현
- **단계**: `BoardServlet`을 통해 게시글 목록을 조회하고 `WEB-INF/views/board/feed.jsp` 화면으로 렌더링하는 파트

---

## 2. 발생한 에러 증상
- 브라우저에서 `/board` 접속 시 **HTTP 500 (Internal Server Error)** 발생
- **핵심 에러 로그**:
  ```text
  jakarta.servlet.ServletException: 게시판 조회 중 오류가 발생했습니다.
      at com.kyobo.web.controller.BoardServlet.doGet(BoardServlet.java:75)
  ...
  org.apache.jasper.JasperException: 행 [82]에서 [/WEB-INF/views/board/feed.jsp]을(를) 처리하는 중 예외 발생
  82: <fmt:formatDate value="${post.createdAt}" pattern="yyyy.MM.dd HH:mm" />
  ...
  근본 원인 (root cause):
  jakarta.el.ELException: 타입 [class java.time.LocalDateTime]인 [2026-10-12T11:20](을)를 [class java.util.Date](으)로 변환할 수 없습니다.
  ```

---

## 3. 문제 원인
- JSTL의 날짜 포맷 태그인 `<fmt:formatDate>`는 Java의 고전 날짜 타입인 **`java.util.Date`** (또는 그 자식 클래스인 `java.sql.Timestamp`)만을 파라미터로 지원함.
- DTO(`BoardPost`, `BoardComment`)에서 `createdAt` 필드를 Java 8 신규 타입인 **`java.time.LocalDateTime`**으로 정의함.
- JSP 렌더링 과정에서 JSTL/EL 내부 엔진이 `LocalDateTime`을 `Date` 타입으로 자동 변환하지 못해 `ELException`이 발생함.

---

## 4. 해결 방법 (방법 1 적용)
DTO와 DAO의 날짜 타입을 JSTL `<fmt:formatDate>`와 기본 호환되는 **`java.sql.Timestamp`**로 통일함.

### ① DTO 수정 (`BoardPost.java`, `BoardComment.java`)
- `LocalDateTime` ➜ `java.sql.Timestamp`로 필드 및 Getter/Setter 변경
```java
// 기존
// private LocalDateTime createdAt;

// 변경
private java.sql.Timestamp createdAt;

public java.sql.Timestamp getCreatedAt() {
    return createdAt;
}
public void setCreatedAt(java.sql.Timestamp createdAt) {
    this.createdAt = createdAt;
}
```

### ② DAO 수정 (`JdbcBoardDao.java`, `JdbcCommentDao.java`)
- `rs.getTimestamp()`를 `toLocalDateTime()`으로 변환하던 과정을 제거하고 `Timestamp` 그대로 세팅
```java
// 기존
// Timestamp ts = rs.getTimestamp("created_at");
// if (ts != null) p.setCreatedAt(ts.toLocalDateTime());

// 변경
p.setCreatedAt(rs.getTimestamp("created_at"));
```

---

## 5. 결과
- 톰캣 재시작 후 `/board` 접속 시 500 에러 해결.
- 피드 카드 상단의 작성일시 및 인라인 댓글 시간이 `yyyy.MM.dd HH:mm` 포맷으로 정상 출력됨을 확인.
