# 06_01 웹서버와 Servlet 기초 실습 프로젝트

이 프로젝트는 자체3 Servlet/JSP 커리큘럼 기준 실습용 골격입니다.

## 폴더
- `src/main/java`: Servlet, DTO, DAO Java 코드
- `src/main/webapp`: JSP, CSS, 정적 파일
- `sql`: 테이블 생성 및 샘플 데이터

## 실행 전 확인
- Tomcat 또는 Servlet 컨테이너 프로젝트로 가져옵니다.
- 패키지명은 `com.kyobo.web` 기준입니다.
- DB 연결 정보는 로컬 환경에 맞게 수정합니다.
